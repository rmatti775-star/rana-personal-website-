مشروع تطبيقات الويب (1) — الموقع الشخصي
اسم الطالبة: رنا الأتاسي
التخصص: الذكاء الاصطناعي

محتويات المشروع:
- index.html: الصفحة الرئيسية
- experience.html: صفحة الخبرات والمهارات
- contact.html: صفحة اتصل بي
- style.css: تنسيق وتصميم الصفحات
- script.js: التفاعل وتبديل اللغة بين العربية والإنجليزية

طريقة التشغيل:
1. فك ضغط الملف.
2. افتحي المجلد.
3. افتحي index.html باستخدام أي متصفح.
4. انتقلي بين الصفحات من القائمة العلوية.

ملاحظة:
نموذج التواصل تجريبي ولا يرسل رسائل إلى بريد إلكتروني أو خادم.
يمكن رفع محتويات المجلد إلى GitHub Pages لنشر الموقع.
